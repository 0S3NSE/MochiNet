🐷 MochiNet

ESP32-S3 wardriving companion + Piglet mesh Core. Flash it right from your browser.

Your browser can't flash here — use desktop Chrome, Edge, or Opera. This page must be served over HTTPS (or localhost) to flash. Project still in ALPHA...

How to flash

  1. Use a Data USB-C cable (not charge-only) on a desktop running Chrome / Edge / Opera.
  2. Plug in the board while holding BOOT and click Install above.
  3. Select the board's serial port in the browser dialog and confirm the install.
  4. When it finishes, the board reboots into MochiNet. Done. Future updates can be done via Mochi access point (OTA)

If the port doesn't appear / install fails

  1. Try a different cable/port first — charge-only cables are the #1 cause.
  2. Put the board in bootloader mode manually: hold BOOT, tap RST, release BOOT, then click Install again.
  3. Close the Arduino IDE / any serial monitor holding the port.

Flashing does not erase your SD card. On first boot MochiNet creates its config; see the project README for wiring and the /wardriver.cfg-style setup.
